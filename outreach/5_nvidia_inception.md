# NVIDIA Inception — application text (English)

NVIDIA Inception is a program for startups (a registered company is usually required). Apply via the NVIDIA Inception page.

**Company / product one-liner.** Oll builds tokenizer-free, continuous-time models that forecast real-world signals with calibrated
uncertainty, run in constant memory on any device, and can learn and forget specific information without retraining.

**Problem.** Industrial, energy and IoT signals are irregular, have missing readings and need trustworthy uncertainty; current models
quantise them into tokens, ignore real time gaps and must be retrained to learn new data.

**Technology and traction.** A 17.5M-parameter model trained on real data only; calibrated densities (CRPS 1.6–5.5× better than a
no-learning reference on four of five held-out sets); below naive baselines on the ETTh2 benchmark at all horizons; one-pass memory with
exact erasure; working web demo [link]; paper [arXiv link]; open weights [Hugging Face link].

**What we need.** GPU credits for scaling (10M → 1B parameters) and technical guidance on efficient continuous-time scan kernels.
